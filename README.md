# Appareil de diagnostic et détection dermatologique

**Projet FABLAB — Université Ibn Tofaïl (UIT)**

## Description du Projet
Ce projet consiste à réaliser un système embarqué capable de détecter et classifier certaines maladies de la peau à partir d'images, en utilisant un modèle de Deep Learning déployé sur une carte **ESP32-CAM**.

## Étapes principales
* **Préparation des données :** Nettoyage et organisation des images (Acné, Eczéma, Psoriasis, Peau saine, etc.).
* **Modèle IA :** Entraînement d'un réseau de neurones (MobileNetV2) pour la classification des images.
* **Système Embarqué :** Prise de photo et exécution du modèle sur **ESP32-CAM**.

## Fichiers du dépôt
* `notebook0f4b136cd6.ipynb` : Code Python pour le filtrage, le nettoyage et la séparation des données (Train / Test).
